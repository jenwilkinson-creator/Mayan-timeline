# Maya event backgrounds

Ten separate original illustrations, generated for this Year 5 lesson. Each landscape image is 1672 × 941 pixels, approximately 16:9, with no interface text or borders. The WebP copies retain the native dimensions without cropping or stretching.

These files are optional for the application: all ten are also embedded in `../index.html`, so the lesson still needs only that HTML file and works offline.

`manifest.json` maps the images to editable Maya event IDs and accessible descriptions. Each corresponding `LESSON.mayaEvents` record in the HTML contains six hotspot positions and short dialogue texts. Update both the embedded template and separate asset when replacing an illustration.

The scenes are interpretive illustrations. Approximate dates and historical qualifications remain in the website’s event captions, including uncertainty about early writing/calendar evidence, earlier pyramid construction, and the continuity of Maya communities.
